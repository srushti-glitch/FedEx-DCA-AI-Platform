# FedEx DCA AI Platform 

An AI-powered Debt Collection & Recovery platform designed for FedEx-style enterprise use cases.
The system prioritizes overdue accounts, enforces SLA rules, and guides agents using SOP-based actions.

---

## Key Features
- AI-based recovery priority scoring
- SLA breach detection
- SOP-driven agent actions
- Centralized dashboard
- Real-time alerts & notifications

---

## AI Pipeline
1. Load overdue account data
2. Apply trained ML recovery model
3. Calculate risk & priority score
4. Check SLA breach rules
5. Recommend next best action
